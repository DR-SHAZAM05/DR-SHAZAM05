## 🧠 Developer Mindset

```python
class Developer:

    def __init__(self):
        self.name = "Rares"
        self.goal = "Become a great software engineer"
        self.status = "Still learning"
        self.quit = False

    def learn(self):
        while not self.quit:
            self.build()
            self.break_something()
            self.debug()
            self.learn_from_it()

    def build(self):
        print("Turning ideas into software...")

    def break_something(self):
        print("It worked five minutes ago.")

    def debug(self):
        print("Why does this work?")

    def learn_from_it(self):
        print("Now I understand it.")
```
